# Session Sound Operator

TRPGセッション用のBGM/SEサウンドボードです。**単一のHTMLファイルだけで動作し、サーバー不要**。UI・操作モデルは [Permille Fader](https://github.com/naokitakatani/permille-fader) の CURRENT / NEXT + クロスフェーダー方式を参考にしています。

画面は **メイン / 詳細編集 / 設定** の3タブ構成。音量の表示・入力はすべて **%(0〜100、小数1桁まで)** です。セッションはヘッダー(タイトルとタブの間)で選べ、通常は「セッション 1」のままで使えます。

## 用語

| 用語 | 意味 |
| --- | --- |
| **セッション** | シーンの入れ物。卓ごと・シナリオごとに分けて使います。基本は1つのままでOK。選択中のセッションがシーンリスト・シーン編集のマスターになります |
| **シーン** | 全BGMチャンネルの音量(%)のセット。音量0%のチャンネルはそのシーンでは不使用(移行完了時に自動停止) |
| **再生順** | シーンの並び順を決める数値。**小数可**なので、1 と 2 の間に差し込みたいときは `1.5` を付けます |
| **割込フェーダー** | シーンとは独立した上乗せフェーダー。実効音量は `max(シーン値, 割り込み値)` |
| **シーンのマスター音量** | そのシーン全体の上限。80%で登録した音源はシーンマスター100%で実質80%が上限になります |
| **シーン別ループ** | 音源をシーンに登録するときの繰り返し設定。同じ音源をシーンAではループON、シーンBではOFFにできます |
| **MASTER(全体)** | BGMとSEの**両方**に効く一番外側のマスター。画面下部の横バー(高さ60px・3本の高さとラベル幅を揃えてあります)の一番左で、青で強調 |
| **BGM MASTER / SE MASTER** | それぞれ全BGM(シーン由来＋割り込み)／全SEに効くマスター。画面下部の横バー |
| **ポン出し** | パッドから単発で鳴らすSE。シーン再生とは独立した系統です |

## 使い方

1. `sound.html` をブラウザで開く(Chrome推奨)
2. **詳細編集 → 音源を検索** で音声ファイル(MP3/WAV/OGG/AAC)を取り込む
   - ライブラリは **BGM列 / SE列の2列**。取り込みボタンも列ごとなので、どちらに登録されるかが常に明確です
   - **任意ID**・タグ・基準音量・ループ有無を設定でき、列ヘッダのクリックで昇順⇄降順ソート(日本語はあいうえお順)。検索とタグ絞り込み(AND)は両列に効きます
   - BGMに **フェーダー割当**(1〜12目安)を入れると割込フェーダーのスロットに並び、SEに **ボタン割当** を入れるとポン出しパッドの並び順になります
   - `→SE` / `→BGM` ボタンで列の間を移動できます
3. **メイン** タブは **「シーン再生」と「ポン出し＋割込フェーダー」の左右分割**。セクションヘッダのクリックで片方だけ畳めます(矢印 `◀︎` `▶︎` が収納/展開の向きを示します)。両方表示時は**境界をドラッグして幅を調整**でき、幅と開閉状態は保存されます

### セクション「シーン再生」

左が **シーンリスト(NEXTを選択)**、右が **シーン遷移** です。

- シーンリスト(選択中セッションのシーンを 再生順 の昇順で表示)をクリックして NEXT を指定 → **GO** で規定の時間で自動遷移
- 右側は上から **手動フェーダー →(区切り)→ GO → 遷移条件 → 手動優先の注記** の順。フェーダー・「手動フェーダー」の文字・GOは**シーン遷移パネルの中央に一直線**で並び、フェーダーを軸に **左が「再生中」・右が「次シーン」** のシーン名が左右対称に出ます(シーン名が長くてもフェーダーの位置は動きません)
- **手動フェーダーを手で動かすと、その位置と速度にリアルタイム追従**してクロスフェードします。**設定したフェード秒数よりも手の動きが優先されます**。途中停止ブレンド・引き返しも可能で、端まで動かし切ると遷移確定
- 共有しているチャンネルは途切れずに音量補間、不要チャンネルは移行完了時に自動停止
- GO後のNEXT送りと `←` `→` キーは**セッション内でループ**します(末尾の次は先頭)
- **■ シーン停止 / ▶ シーン再開** でシーン由来の音だけを止めて戻せます(割込フェーダーとポン出しは鳴り続けます)。再開すると、**そのシーンに登録したSEはループ・単発を問わず先頭から鳴り直します**(シーンに入り直したときと同じ)
- セクションの**一番下の操作バー**に、よく使う5つのボタンがまとまっています: **◉ 今の音をシーンに入れる / 上書き / ■ シーン停止・▶ シーン再開 / MUTE ALL / ■ ALL STOP・▶ ALL START**
- 「◉ 今の音をシーンに入れる」でいま鳴っている音量を新規シーンとして保存。**セッション / 再生順 / Scene Name / IN方法・OUT方法 / シーンのマスター音量を1つのフォームで入力**します。「上書き」は再生中シーンに対して同じフォームで実行
  - 保存値は `max(シーン値, 割り込み値)` の**焼き込み**です。保存すると割り込みフェーダーは0%に戻りますが、**聞こえる音は保存前後で変わりません**
- **MUTE ALL** は鳴っている音を即ミュート(シーンの保存値は変わりません)。もう一度押すと元の音に戻ります。**ポン出しと割込フェーダーも含めた全体**に効きます
- **ALL STOP** は**シーンの音だけ**を止めます(ポン出しと割込フェーダーは鳴り続けます)。もう一度押すと **ALL START** でシーンが戻り、シーン登録SEは先頭から鳴り直します
- シーンリスト各行の **🎚️** から、そのシーンの音量設定・音源の差し替え・削除ができます

### セクション「ポン出し＋割込フェーダー」

パッドもフェーダーも、**操作した瞬間(待ち時間0)に音が鳴ります**(必要な音源は起動時に先読みデコードしています)。

> この系統は**シーン再生から完全に独立**しています。シーン停止・シーン再開・GO(遷移)・ALL STOP / ALL START は、パッドの再生や割込フェーダーの値・音量に一切影響しません。逆にパッドや割込フェーダーの操作でシーンの状態が変わることもありません。全体に効くのは **MUTE ALL** と **MASTER(全体)** だけです。

- **上段: ポン出しパッド** — 正方形グリッド。クリックまたは数字キー `1`〜`9` でカットイン。**再生中にもう一度押すと停止**します(再生中のパッドはオレンジのリングで点灯)。**ボタン割当**の番号順に並び、9件を超えるとバンク(A/B/C…)に分かれて数字キーは現在バンクの1〜9に対応します
  - パッドごとに**色を指定**できます(詳細編集のSE行の「色」列 → スウォッチからカラーパレット)。色は自動保存され、エクスポート／インポートやDrive同期でも保たれます
- **下段: 割込BGMフェーダー** — **フェーダー割当**を入れたBGMだけがスロット番号順に並びます。**シーンの保存値は一切書き換えません**。シーン遷移後も割り込み値は維持され、0%に戻せば通常のシーン値に戻ります
- 各フェーダーの下の **■ 停止** は、**割り込みの上乗せ分だけ**を解除します
  - そのチャンネルをシーンも使っている場合: **音は途切れず**、シーンの音量まで下がるだけです(枠が緑になり「割り込み解除」と表示)
  - シーン側で使っていない場合: 再生を停止し、ボタンが **▶ 途中から / ⏮ 最初から** の2択になって再開位置を選べます
  - どちらの場合もシーンの保存値は変わりません

### シーンの遷移(IN方法 / OUT方法)

遷移は**シーンごとに「IN方法」と「OUT方法」を別々に指定**します。**OUTは出ていくシーン**の設定、**INは入ってくるシーン**の設定が使われます。それぞれ **クロスフェード / フェード / カット** から選び、秒数も別々に設定できます。

> **クロスフェード連動**: 前のシーンのOUTがクロスフェードのときは、次のシーンのINも**同じ時間のクロスフェード**になります(2つのシーンが1つの動きとしてすれ違うため)。このとき次のシーンの**IN設定は前シーンのOUTで上書き保存**されます。連動中はシーン編集と🎚️設定のIN欄が読み取り専用になり、シーンリストにも `IN連動` と表示されます。前シーンのOUTをクロスフェード以外に変えるとIN欄は編集できるようになりますが、**上書き前の値には戻りません**(必要なら入れ直してください)。

| 組み合わせ | 動き |
| --- | --- |
| OUT クロス ＋ IN クロス | 同時にすれ違う(所要時間は長い方) |
| OUT フェード ＋ IN フェード | **順番に**行う。手動フェーダーなら OUT の持ち分を過ぎた位置で前シーンが0になり、そこから次シーンがIN。所要時間は OUT+IN |
| OUT フェード ＋ IN カット | OUTをフェードし、完了と同時にINをカットイン |
| OUT カット ＋ IN カット | 一瞬で切り替え |
| OUT カット ＋ IN フェード | OUTを即0にして、INをフェードイン |

例: 再生順1に「OUT方法=フェード 2秒」、再生順2に「IN方法=フェード 2秒」を設定すると、手動フェーダーの50%で再生順1が0になり、50%を過ぎたところから再生順2がフェードインしてきます。設定できる場所はシーン保存フォーム・シーンカード・🎚️設定の3箇所です。

### 詳細編集

- **セッション管理** — 「現在のセッション：」で選んだセッションが、シーン編集とメイン画面のシーンリストのマスターになります。ボタンは **改名 → ＋ 新規作成 → 削除** の順。新規作成と改名はどちらも同じインライン入力(「セッション名：」)で、Enterで確定・Escで取消。セッション名が完全に同じものが複数あるときだけ、名前のうしろに(シーン数)が付きます
- **シーン編集** — 最上部の**ワイン色の枠が入力用カード**です。再生順 / シーン名(任意) / IN方法・OUT方法とその秒数 / シーンのマスター音量 / 音源と音量 を入れて「＋ 追加登録」すると、そのまま下の一覧に並びます。ボタンは **音源選択 ▼ → 一時保存 → ＋ 追加登録** の順で、高さは入力欄と揃えてあります。登録済みカードは「音量を編集 ▾」で1枚ずつ開きます
  - **音源選択** を押すまで音源一覧は表示されません。押すと **左にBGM・右にSE**の一覧が開きます
  - 各行は左から **🔼(入れる・外す) / 曲名 / 音量% / 試聴 / ループ(シーン別)** の左寄せ。**試聴**はその行に入れた%の音量で鳴り、もう一度押す・別の音源を試聴する・パネルを閉じるで止まります。追加時の初期音量は **100%**
  - 各列で名前検索と(名前 / 任意ID / タグ)のソートができます。任意IDとタグは曲名にマウスを乗せると出ます
  - BGM一覧の先頭にある **音無しシーン** を選ぶと、全チャンネルが0%の無音シーンになります
  - **シーンにはBGMとSEを両方**登録できます。登録したSEはそのシーンに切り替わった瞬間に鳴り、**ループONならそのシーンの再生中ずっと繰り返します**(別シーンへ移る・シーン停止・ALL STOPで止まります)。シーン再開時はループ・単発とも先頭から鳴り直します
  - 音源を選ぶと、カードに**選択済みリストが自動で表示**されます。1行につき `BGM/SE【曲名】 音量：n%、ループ：ON/OFF` の形式です
  - **一時保存** を押すと、まだ追加登録していない入力内容(再生順・シーン名・IN/OUT・マスター音量・選択音源・音量・シーン別ループ)をまるごと退避できます。ボタンは「一時保存データに戻す」に変わり、**1回押すと保存時点に戻ってボタンは「一時保存」に戻ります**(そのあと押せば、その時点の内容を新しく退避します)。音源選択の開閉状態は復元しても変わりません。追加登録すると退避データは破棄されます(セッションごとに保持・ページ再読み込みでは残りません)
- **音源を検索** — 検索とタグ絞り込み(AND)は両方の列に効きます。タグは自由記述ですが、既存のタグは入力欄の候補から選べます。選択中のタグは `✕` 付きで表示され、クリックか「タグ絞り込みを解除」で外せます

はじめて触る場合は **設定 → デモ一式を生成** でデモ音源とシーンが自動生成されます(IN/OUTの組み合わせを一通り使ったシーンと、SE付きのシーン・音無しシーンができます)。動作確認用に **ダミー音源を200件生成**(開発用)もあります。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Enter` | GO(シーン切替) |
| `←` / `→` | NEXTシーン選択(セッション内でループ) |
| `Space` | ALL STOP(シーンの音だけ) / もう一度押すと ALL START(シーンSEは先頭から鳴り直し) |
| `1`〜`9` | ポン出しパッド再生 / 再押下で停止(現在バンク) |

## データ保存

- 既定は**ローカルモード**: 音源Blobとメタデータを IndexedDB に永続保存(完全オフライン動作)
- **エクスポート / インポート**: 全データを1ファイル(`.ssopack.json`)に書き出し、別端末へ移行可能
- データ形式は **version 5**。旧データは起動時に自動移行されます
  - v1 → 既存シーンは「セッション 1」に所属し、再生順が 1, 2, 3… と付与されます
  - v2(遷移モード1〜5) → IN方法 / OUT方法 の組み合わせに移行されます(クロスフェード→OUTクロス＋INクロス、F.OUT→F.IN→OUTフェード＋INフェード、カット→OUTカット＋INカット など)
  - v3 → シーン別ループを音源共通のループ設定から初期化(以後は独立)
  - v4 → パッド色に既定色を補完
  - v1〜v4 の `.ssopack.json` もそのままインポートできます

## Google Drive 同期(任意)

自分のGoogleアカウントのDriveに `SessionSoundOperator` フォルダを作り、`state.json` と音源ファイルを同期します。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成し、**OAuthクライアントID(ウェブアプリケーション)** を発行
   - スコープは `drive.file` のみ(このアプリが作成したファイルにしかアクセスしません)
   - 承認済みJavaScript生成元に配信URLのオリジンを登録
2. アプリの **設定 → Google Drive 同期** にクライアントIDを入力して「接続して同期」

> **注意**: OAuthの仕様上、**httpsで配信されたURLで開いている必要があります**。ローカルファイル直開き(`file://`)ではDrive同期は使えません。GitHub Pages(Settings → Pages → main ブランチ)で公開するのが手軽です。
>
> GitHub Pagesで公開した場合のURLは `https://onoayami.github.io/session_sound_operator/sound.html` です(`index.html` ではないので末尾のファイル名まで含めて開いてください)。

## OBS連携

- ブラウザのタブ音声をOBSの「アプリケーション音声キャプチャ」等で取り込む
- またはOBSの**ブラウザソース**として配信URLを読み込む(操作は別ウィンドウ推奨)

## 技術メモ

- 再生エンジン: Web Audio API(マスター / シーン / SE のゲインバス構成)
- 内部の音量値は 0〜1000 で保持し、表示・入力時に % へ変換しています
- 外部依存はGoogle Identity Services(Drive同期利用時のみ動的読み込み)だけ
- ビルド不要。`sound.html` を配るだけで動きます
