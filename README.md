# Session Sound Operator

TRPGセッション用のBGM/SEサウンドボードです。**単一のHTMLファイルだけで動作し、サーバー不要**。UI・操作モデルは [Permille Fader](https://github.com/naokitakatani/permille-fader) の CURRENT / NEXT + クロスフェーダー方式を参考にしています。

画面は **メイン / 詳細編集 / 設定** の3タブ構成。音量の表示・入力はすべて **%(0〜100、小数1桁まで)** です。セッションはヘッダー(タイトルとタブの間)で選べ、通常は「セッション 1」のままで使えます。

## 用語

| 用語 | 意味 |
| --- | --- |
| **セッション** | シーンの入れ物。卓ごと・シナリオごとに分けて使います。基本は1つのままでOK。選択中のセッションがシーンリスト・シーン編集のマスターになります |
| **シーン** | 全BGMチャンネルの音量(%)のセット。音量0%のチャンネルはそのシーンでは不使用(移行完了時に自動停止) |
| **再生番号** | シーンの並び順を決める数値。**小数可**なので、1 と 2 の間に差し込みたいときは `1.5` を付けます |
| **割込フェーダー** | シーンとは独立した上乗せフェーダー。実効音量は `max(シーン値, 割り込み値)` |
| **シーンのマスター音量** | そのシーン全体の上限。80%で登録した音源はシーンマスター100%で実質80%が上限になります |
| **シーン別ループ** | 音源をシーンに登録するときの繰り返し設定。同じ音源をシーンAではループON、シーンBではOFFにできます |
| **ループ間隔** | シーンに登録したSEをループさせるときの、鳴り終わってから次に鳴るまでの待ち時間(秒)。未指定なら従来どおり切れ目なく連続ループします |
| **任意ID** | 音源に付ける識別子(数字のみ)。**「任意：IDを自動連番付与する」がONのときだけ**、新規に取り込んだ音源の未設定IDに、既存の最大値+1から連番を付与します(削除済みの欠番は再利用しません)。手動でも編集できます(空欄にすると「IDなし」) |
| **MASTER(全体)** | BGMとSEの**両方**に効く一番外側のマスター。画面下部の横バー3本のうち一番左で、青で強調 |
| **BGM MASTER / SE MASTER** | それぞれ全BGM(シーン由来＋割り込み)／全SEに効くマスター。画面下部の横バー |
| **マスターバー** | 画面下部の3本の横バー(MASTER(全体)／BGM MASTER／SE MASTER)。**「■ 全停止」「ミュート」の2ボタンは3本の外側の専用領域**にあり、3本のフェーダーは常に正確に3等分です(どのフェーダーにもボタンは付きません)。「■ シーン停止」はマスターバーではなく、シーン遷移パネルのキー操作説明の下に単独・中央揃えであります。バーは低め・横棒とつまみは小さめで、数値は読める大きさのままです |
| **ポン出し** | パッドから単発で鳴らすSE。シーン再生とは独立した系統です。パッドの背景色は不透明(透過度0%)です |

## 使い方

1. `sound.html` をブラウザで開く(Chrome推奨)
2. **詳細編集 → 音源検索＋割込フェーダー/ポン出し設定管理** で音声ファイル(MP3/WAV/OGG/AAC)を取り込む
   - 音源の一覧管理(**音源一覧管理 / SE一覧管理**)と、割込フェーダー・ポン出しの**割当設定は別UI**に分かれています。検索・ソート・ページングも**カード側（割当ミニ一覧用）と一覧表側で完全に独立**しており、どちらを検索・並べ替えても、もう一方の件数・並び順は変わりません
   - **音源一覧管理(BGM)：SE一覧管理**の表示幅は **6:4**(BGM側が広い)です
   - **音源一覧管理 / SE一覧管理**の各行は左から **試聴 / ID / 名前 / タグ / 基準音量 / (BGMはループ) / 長さ / 移動・削除**。フェーダー割当・ボタン割当・色はここには無く、名前欄が広く表示されます
   - **タグは複数登録**できます(ピル型で表示され、`✕` で1件ずつ外せます。`＋タグ` 欄に入力して確定すると追加)
   - **基準音量**はバー(幅は列の4/5)の下に % が中央揃えで表示され、数字を直接入力しても変えられます
   - 列ヘッダのクリックで昇順⇄降順ソート(日本語はあいうえお順)。**ID列・名前列は非アクティブでも淡色の▲▼を常時表示**します。検索は両列に効きます
   - 「**任意：IDを自動連番付与する**」チェックボックス(既定ON。**音源一覧管理／SE一覧管理**の各ボックス内、表の上にあり、2つは同じ設定を共有・同期します)をOFFにすると、以後に取り込んだ音源には自動で連番が付かなくなります
   - 検索ボックスの下にある**割当ミニ一覧**で、BGMは**フェーダー番号**、SEは**ボタン番号と色**を、数字を直接入力して設定します(候補選択ではありません)。**空欄にすると割当が解除**されます。BGM側・SE側それぞれに**「全割当解除」**ボタン(確認あり)があります(SE側は番号だけを解除し、色は変わりません)
   - 任意IDでの検索は、単一番号・範囲(`1-10` または `1〜10`)・カンマ区切り(`1,3,5`)、およびこれらの併用に対応しています
   - `→SE` / `→BGM` ボタンで列の間を移動できます
3. **メイン** タブは **「シーン再生」と「ポン出し＋割込フェーダー」の左右分割**。セクションヘッダのクリックで片方だけ畳めます(矢印 `◀︎` `▶︎` が収納/展開の向きを示します)。両方表示時は**境界をドラッグして幅を調整**でき、幅と開閉状態は保存されます

### セクション「シーン再生」

左が **シーンリスト(NEXTを選択)**、右が **シーン遷移** です(「シーン遷移」の見出しは枠付きボックスの内側・左上にあります)。

- シーンリスト(選択中セッションのシーンを 再生番号 の昇順で表示)をクリックして NEXT を指定 → **GO** で規定の時間で自動遷移
- 右側は上から **手動フェーダー →(区切り)→ GO → 遷移条件の枠** → **キー操作の説明(4項目)** → **■ シーン停止(単独・中央揃え)** → **◉ 現在の再生状態を新シーンとして追加 / 上書き** の順。フェーダー・「手動フェーダー」の文字・GOは**枠の中央に一直線**で並び、フェーダーを軸に **左が「再生中」・右が「次シーン」** のシーン名が左右対称に出ます(シーン名が長くてもフェーダーの位置は動きません)
- **手動フェーダーを手で動かすと、その位置と速度にリアルタイム追従**してクロスフェードします。**設定したフェード秒数よりも手の動きが優先されます**。途中停止ブレンド・引き返しも可能で、端まで動かし切ると遷移確定
- 共有しているチャンネルは途切れずに音量補間、不要チャンネルは移行完了時に自動停止
- GO後のNEXT送りと `←` `→` キーは**セッション内でループ**します(末尾の次は先頭)
- **停止系の3ボタン**: **■ 全停止・▶ 全再開**と**ミュート**は画面下部の**マスターバーの、3本のフェーダーとは別の専用領域**に横並び(全停止→ミュートの順)。**■ シーン停止・▶ シーン再開**はマスターバーには無く、シーン遷移側のキー操作説明の**下に単独・中央揃え**であります
- **■ シーン停止 / ▶ シーン再開** でシーン由来の音だけを止めて戻せます(割込フェーダーとポン出しは鳴り続けます)。再開すると、**そのシーンに登録したSEはループ・単発を問わず先頭から鳴り直します**(シーンに入り直したときと同じ)
- **■ シーン停止ボタンの下**には保存系の2つだけが並びます: **◉ 現在の再生状態を新シーンとして追加 / 上書き**
- 「◉ 現在の再生状態を新シーンとして追加」でいま鳴っている音量を新規シーンとして保存。開く画面は**詳細編集のシーンカードと全く同じUI**で、セッションだけ別に選べます。「上書き」は再生中シーンに対して同じ画面で実行
  - 保存値は `max(シーン値, 割り込み値)` の**焼き込み**です(ポン出しの分も含みます)。保存すると割り込みフェーダーは0%に戻りますが、**聞こえる音は保存前後で変わりません**
- **ミュート** は **MASTER(全体) のゲージを0にするだけ**です。シーン・ポン出し・割込がいったん全部0%になりますが再生は止まらないので、もう一度押す(または MASTER のゲージを動かす)と**そのまま曲の続きから**聞こえます(ミュート中に鳴り終わった単発SEは戻りません)
- **■ 全停止** は**シーン・ポン出し・割込フェーダーを全部**止めます。もう一度押すと **▶ 全再開** で止める直前の状態(シーン音量・割込の値・鳴っていたSE)から全再生が始まります(SEは先頭から)
- **全停止中でも「▶ シーン再開」でシーンだけ先に戻せます**。残りの割込・ポン出しは全停止側が持っているので、そのあと **▶ 全再開** で戻ります
- 停止系はどの順番で押しても音量情報が失われません(内部では「何を黙らせたか」を1本のスタックで管理しています)

| ボタン | 何が止まるか | 戻し方 |
| --- | --- | --- |
| **■ シーン停止** | シーンの音だけ(割込・ポン出しは継続) | ▶ シーン再開 / `Space` |
| **■ 全停止** | シーン＋ポン出し＋割込のすべて(再生自体を停止) | ▶ 全再開(シーンだけ先に戻すなら ▶ シーン再開) |
| **ミュート** | MASTER(全体)のゲージが0になるだけ(**再生は続いたまま**) | もう一度押す / MASTERのゲージを動かす |

> **全停止中に音を出す操作をしたとき**: 割込フェーダーやポン出しを触ると、画面内に確認バーが出て3択を選べます(ダイアログではないので操作は止まりません)。
> ① 元の状態から始める ② 全部クリアしてこの操作だけ鳴らす ③ 元の状態＋この操作も鳴らす。GO(シーン遷移)は確認なしで、全停止を解除して遷移します。
> シーンだけ先に戻してある場合は、文言が「残りは戻さずこの操作だけ鳴らす」などに変わります。
- シーンリスト各行の **✏️** から、そのシーンを編集できます。開く画面は**詳細編集の既存シーン編集と全く同じUI**(音源選択・音源を編集・複製・削除まで同じ)です

### セクション「ポン出し＋割込フェーダー」

パッドもフェーダーも、**操作した瞬間(待ち時間0)に音が鳴ります**。先読みは「SEは全件」「割込BGMは60秒以下」に絞ってあり(長い曲を全部展開するとメモリを使いすぎるため)、**シーンの音源はNEXTに選んだ時点で先読み**されます。

> この系統は**シーン再生から完全に独立**しています。シーン停止・シーン再開・GO(遷移)は、パッドの再生や割込フェーダーの値・音量・表示に一切影響しません。**シーンが同じ音源を鳴らしていても、割込フェーダー側は何も反応しません**(値は0%のまま・停止ボタンも無効のまま)。逆にパッドや割込フェーダーの操作でシーンの状態が変わることもありません。全体に効くのは **■ 全停止**・**ミュート**・**MASTER(全体)** だけです。

- **上段: ポン出しパッド** — 正方形グリッド。クリックまたは数字キー `1`〜`9` でカットイン。**再生中にもう一度押すと停止**します(再生中のパッドはオレンジのリングで点灯)。**ボタン割当**の番号順に並び、9件を超えるとバンク(A/B/C…)に分かれて数字キーは現在バンクの1〜9に対応します
  - パッドごとに**色を指定**できます。パッド右上の**🎨ボタン**、または詳細編集の割当ミニ一覧の色スウォッチのどちらからでもカラーパレットが開き、変更はもう片方にも即時反映されます(🎨はパッドの再生/停止とは独立したボタンなので、押しても音は鳴りません)。色は自動保存され、エクスポート／インポートやDrive同期でも保たれます
- **下段: 割込BGMフェーダー** — **フェーダー割当**を入れたBGMだけがスロット番号順に並びます。**シーンの保存値は一切書き換えません**。シーン遷移後も割り込み値は維持され、0%に戻せば通常のシーン値に戻ります
- 各フェーダーの下の **■ 停止** は、**割り込みの上乗せ分だけ**を解除します。押すとボタンが **▶ 途中から / ⏮ 最初から** の2択になり、再開位置を選べます
  - そのチャンネルをシーンも使っている場合、**シーンの音は止まりません**(割込の上乗せ分だけが下がります)
  - シーンの保存値は変わりません

### シーンの遷移(IN方法 / OUT方法)

遷移は**シーンごとに「IN方法」と「OUT方法」を別々に指定**します。**OUTは出ていくシーン**の設定、**INは入ってくるシーン**の設定が使われます。それぞれ **クロスフェード / フェード / カット** から選び、秒数も別々に設定できます。

> **クロスフェード連動**: 前のシーンのOUTがクロスフェードのときは、次のシーンのINも**同じ時間のクロスフェード**になります(2つのシーンが1つの動きとしてすれ違うため)。このとき次のシーンの**IN設定は前シーンのOUTで上書き保存**されます。連動中はシーン編集と ✏️ のIN欄が読み取り専用になり、シーンリストにも `IN連動` と表示されます。前シーンのOUTをクロスフェード以外に変えるとIN欄は編集できるようになりますが、**上書き前の値には戻りません**(必要なら入れ直してください)。

| 組み合わせ | 動き |
| --- | --- |
| OUT クロス ＋ IN クロス | 同時にすれ違う(所要時間は長い方) |
| OUT フェード ＋ IN フェード | **順番に**行う。手動フェーダーなら OUT の持ち分を過ぎた位置で前シーンが0になり、そこから次シーンがIN。所要時間は OUT+IN |
| OUT フェード ＋ IN カット | OUTをフェードし、完了と同時にINをカットイン |
| OUT カット ＋ IN カット | 一瞬で切り替え |
| OUT カット ＋ IN フェード | OUTを即0にして、INをフェードイン |

例: 再生番号1に「OUT方法=フェード 2秒」、再生番号2に「IN方法=フェード 2秒」を設定すると、手動フェーダーの50%で再生番号1が0になり、50%を過ぎたところから再生番号2がフェードインしてきます。設定できる場所はシーンカード・✏️・「◉ 現在の再生状態を新シーンとして追加」の3箇所ですが、**UIはどれも同じシーンカード**です。

### 詳細編集

- **セッション管理** — 「現在のセッション：」で選んだセッションが、シーン編集とメイン画面のシーンリストのマスターになります。ボタンは **改名 → ＋ 新規作成 → 削除** の順。新規作成と改名はどちらも同じインライン入力(「セッション名：」)で、Enterで確定・Escで取消。セッション名が完全に同じものが複数あるときだけ、名前のうしろに(シーン数)が付きます
- **シーン編集** — 最上部の**ワイン色の枠が入力用カード**です。**再生番号 / シーン名(任意) / 音源選択 ▼ / マスター音量 / 一時保存 / ＋ 追加登録** が1行に並び、その下に **IN方法・IN秒**の行、さらにその下に**OUT方法・OUT秒**の行が(2行に分けて)入ります。「＋ 追加登録」でそのまま下の一覧に並びます。ボタンの高さは入力欄と揃え、IN秒・OUT秒の欄は上下矢印なしの小さめサイズです
  - 登録済みカードは右上が **複製 / 削除** の2つ。**複製**を押すと同じ内容のシーンが1つ増えます
  - **音源選択** を押すまで音源一覧は表示されません。押すと **左に「BGM一覧」・右に「SE一覧」** が開きます
  - 各行は左から **🔼(入れる・外す) / 曲名 /(空白)/ 音量 [ n % ] / 試聴 / ループ(シーン別) /(SEのループONならループ間隔)/ 　　タグ：(ピル型)** の左寄せ。`%` は枠の中に表示されるだけで、編集するのは数字だけです。**試聴**はその行に入れた%の音量で鳴り、もう一度押す・別の音源を試聴する・パネルを閉じるで止まります。追加時の初期音量は **100%**
  - 検索欄の**左にソートトグル(名前 / タグ / 任意ID)**があり、選んだ種別に合わせて検索UIが変わります: 名前→「名前を検索」、タグ→「タグを入力して検索」＋登録済みタグの**トグル(複数選択可)**、任意ID→「IDを入力して検索」＋登録済みIDの**トグル(複数選択可)**。トグルを複数選んだときは**選んだどれかに当たれば表示**されます
  - BGM一覧の先頭にある **音無しシーン** を選ぶと、全チャンネルが0%の無音シーンになります
  - **シーンにはBGMとSEを両方**登録できます。登録したSEはそのシーンに切り替わった瞬間に鳴り、**ループONならそのシーンの再生中ずっと繰り返します**(別シーンへ移る・シーン停止・全停止で止まります)。シーン再開時はループ・単発とも先頭から鳴り直します
    - SEのループにチェックを入れると **「ループ間隔の指定：[ n ]秒」** が出ます。秒数を入れると**鳴り終わってからその秒数だけ待って鳴り直します**。空欄・0なら従来どおり切れ目なく連続ループします
  - 音源を選ぶと、カードに**選択済みリストが自動で表示**されます。1行につき `🎶 BGM【曲名】 音量：n%、ループ：ON/OFF`(SEは `🎺`、ループ間隔を入れていれば `（間隔 n秒）`)の形式で、右端に**「音源を編集」「削除」**の2ボタンがあります
  - **「音源を編集」は音源ごとのボタン**です。押すとその行の直下だけにアコーディオンで音量バー・%・ループが開きます(名前・音量バー・%・ループは横一列で縦位置が揃い、「ループ」の文字とチェックボックスの間も広めです)。**複数の音源を同時に開けます**(1つ開いても他は閉じません)。開閉状態は再描画をまたいで保持されます。**削除は選択済みリスト側の「削除」ボタン**(枠付き・赤文字。シーンカードの削除ボタンと同じ見た目)だけにあり、展開した編集行の側にはありません
    - **SEの編集行にはループ間隔欄が常に表示**されます。ループが**OFFのあいだは入力欄が無効化(グレーアウト)**され、値そのものは消えません。ONに戻すと直前に入れていた値がそのまま使えます
  - **一時保存** を押すと、いまの入力内容(再生番号・シーン名・IN/OUT・マスター音量・選択音源・音量・シーン別ループ・ループ間隔)をまるごと退避できます。**登録済みシーンでも、何か編集を入れると一時保存のボタンが出ます**。ボタンは「一時保存データに戻す」に変わり、**1回押すと保存時点に戻ってボタンは「一時保存」に戻ります**
    - 退避したデータは**復元しても消えません**。消える(置き換わる)のは **別の内容で「一時保存」を押し直したとき**と、**「＋ 追加登録」で正式なシーンとして登録したとき**だけです
    - 「音源選択」や各行の「音源を編集」の開閉状態は復元しても変わりません。退避データは入力カードならセッションごと・登録済みならシーンごとに保持され、ページ再読み込みでは残りません
- **音源検索＋割込フェーダー/ポン出し設定管理** — シーン編集の音源選択と**同じソートトグル＋検索UI**です(名前 / タグ / 任意ID、タグとIDはトグルで複数選択可、任意IDは範囲・単一・カンマ区切りの併用も可)。検索は下の2つの列どちらにも効きます。タグは自由記述ですが、既存のタグは入力欄の候補から選べます

はじめて触る場合は **設定 → デモ一式を生成** でデモ音源とシーンが自動生成されます(IN/OUTの組み合わせを一通り使ったシーンと、SE付きのシーン・音無しシーンができます)。動作確認用に **ダミー音源を200件生成**(開発用)もあります。

## データ保存

- 既定は**ローカルモード**: 音源Blobとメタデータを IndexedDB に永続保存(完全オフライン動作)
- **エクスポート / インポート**: 全データを1ファイル(`.ssopack.json`)に書き出し、別端末へ移行可能
  - インポートは **先にファイル全体を検証してから** 書き込み、最後に不要な音源だけを消します。壊れたファイルを読んでも**この端末のデータは1件も消えません**(「取り込めませんでした」と表示して何も変更しません)
  - 音源データ(blobs)が入っていないファイルのときは、その旨を確認してから取り込みます
- データ形式は **version 8**。旧データは起動時に自動移行されます
  - v1 → 既存シーンは「セッション 1」に所属し、再生番号が 1, 2, 3… と付与されます
  - v2(遷移モード1〜5) → IN方法 / OUT方法 の組み合わせに移行されます(クロスフェード→OUTクロス＋INクロス、F.OUT→F.IN→OUTフェード＋INフェード、カット→OUTカット＋INカット など)
  - v3 → シーン別ループを音源共通のループ設定から初期化(以後は独立)
  - v4 → パッド色に既定色を補完
  - v5 → **SEのループ間隔**(`loopGaps`)の入れ物を追加。古い単一タグは複数タグの配列に引き継がれます
  - v6 → 起動時／インポート時に無条件で任意IDを自動採番していた処理を廃止。任意IDは**「任意：IDを自動連番付与する」をONにしたときだけ**、新規取込音源に付与されます(既存の任意IDはそのまま残ります)
  - v7 → 自動連番の既定値を ON に変更(**新規に作成したデータのみ**。既存データを読み込んだときに、明示的に OFF にしている設定を勝手に ON へ書き換えることはありません)
  - v1〜v7 の `.ssopack.json` もそのままインポートできます

## Google Drive 同期(任意)

自分のGoogleアカウントのDriveに `SessionSoundOperator` フォルダを作り、`state.json` と音源ファイルを同期します。

> **同期の失敗は必ず画面に出ます**。トークン切れ(401)やアップロード失敗が起きるとヘッダーのバッジが **「Drive 未同期」(オレンジ)** に変わり、設定画面のログに理由が出ます。
> 別端末との衝突で**どちらかを上書きする場合は、上書きされる側を先に Drive へ退避**します(`state_local_backup.json` / `state_remote_backup.json`)。退避したときもバッジとログで警告します。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成し、**OAuthクライアントID(ウェブアプリケーション)** を発行
   - スコープは `drive.file` のみ(このアプリが作成したファイルにしかアクセスしません)
   - 承認済みJavaScript生成元に配信URLのオリジンを登録
2. アプリの **設定 → Google Drive 同期** にクライアントIDを入力して「接続して同期」

> **注意**: OAuthの仕様上、**httpsで配信されたURLで開いている必要があります**。ローカルファイル直開き(`file://`)ではDrive同期は使えません。GitHub Pages(Settings → Pages → main ブランチ)で公開するのが手軽です。
>
> GitHub Pagesで公開した場合のURLは `https://onoayami.github.io/session_sound_operator/sound.html` です(`index.html` ではないので末尾のファイル名まで含めて開いてください)。

## 技術メモ

- 再生エンジン: Web Audio API(マスター / シーン / SE のゲインバス構成)
- 内部の音量値は 0〜1000 で保持し、表示・入力時に % へ変換しています
- SEのループ間隔は連続ループではなく「鳴り終わり → `setTimeout` で待機 → 鳴らし直し」で実装しています(停止時に待機タイマーもまとめて片付けます)
- スライダー・数値入力の `input`(ドラッグ中/入力中)イベントでは全体再描画をせず、`change`(操作確定時)でのみ行うようにしています。ドラッグ中に要素が作り直されて操作が飛ぶ現象(明滅)を避けるための対応です
- 手動フェーダーで遷移を開始した直後の `await` が明けた時点で、他の操作(0%に戻す・GOによる自動遷移への切り替わりなど)が入っていないかを必ず再確認します
- IndexedDBを開けない場合(`file://` 直開き・プライベートブラウズ等)は、画面上部にエラーメッセージを表示します(以前は無反応のまま固まっていました)
- 編集内容は400ms後にまとめて保存されますが、タブを閉じる・非表示になる瞬間(`pagehide` / `visibilitychange`)には待たずに即時保存します
- 外部依存はGoogle Identity Services(Drive同期利用時のみ動的読み込み)だけ
- ビルド不要。`sound.html` を配るだけで動きます
