# Session Sound Operator

TRPGセッション用のBGM/SEサウンドボードです。**単一のHTMLファイルだけで動作し、サーバー不要**。UI・操作モデルは [Permille Fader](https://github.com/naokitakatani/permille-fader) の CURRENT / NEXT + クロスフェーダー方式を参考にしています。

画面は **メイン / 詳細編集 / 設定** の3タブ構成。音量の表示・入力はすべて **%(0〜100、小数1桁まで)** です。セッションはヘッダー(タイトルとタブの間)で選べ、通常は「セッション 1」のままで使えます。

## 用語

| 用語 | 意味 |
| --- | --- |
| **セッション** | シーンの入れ物。卓ごと・シナリオごとに分けて使います。基本は1つのままでOK。選択中のセッションがシーンリスト・シーン編集のマスターになります |
| **シーン** | 全BGMチャンネルの音量(%)のセット。音量0%のチャンネルはそのシーンでは不使用(移行完了時に自動停止) |
| **Scene ID** | シーンの並び順を決める数値。**小数可**なので、1 と 2 の間に差し込みたいときは `1.5` を付けます |
| **割り込みフェーダー** | シーンとは独立した上乗せフェーダー。実効音量は `max(シーン値, 割り込み値)` |
| **BGM MASTER / SE MASTER** | それぞれ全BGM(シーン由来＋割り込み)／全SEに効く独立したマスター。画面下部の横バー |

## 使い方

1. `sound.html` をブラウザで開く(Chrome推奨)
2. **詳細編集 → 音源ライブラリ** で音声ファイル(MP3/WAV/OGG/AAC)を取り込む
   - ライブラリは **BGM列 / SE列の2列**。取り込みボタンも列ごとなので、どちらに登録されるかが常に明確です
   - **任意ID**・タグ・基準音量・ループ有無を設定でき、列ヘッダのクリックで昇順⇄降順ソート(日本語はあいうえお順)。検索とタグ絞り込み(AND)は両列に効きます
   - BGMに **フェーダーNo**(1〜12目安)を入れると、割り込みフェーダーのスロットに並びます
   - `→SE` / `→BGM` ボタンで列の間を移動できます
3. **メイン** タブは **「シーン再生」と「フェーダー(割り込み)」の左右分割**。セクションヘッダのクリックで片方だけ畳めます。両方表示時は**境界をドラッグして幅を調整**でき、幅と開閉状態は保存されます

### セクション「シーン再生」

- 上から **再生中 → NEXT選択(シーンリスト) → クロスフェーダー → GO** の順。クロスフェーダーとGOは同じ枠で括られており、どちらもシーン遷移の操作です
- シーンリスト(選択中セッションのシーンを Scene ID 昇順で表示)をクリックして NEXT を指定 → **GO** で規定のフェード時間で自動遷移
- **クロスフェーダーを手で動かすと、その位置と速度にリアルタイム追従**してクロスフェードします。途中停止ブレンド・引き返しも可能で、端まで動かし切ると遷移確定
- 共有しているチャンネルは途切れずに音量補間、不要チャンネルは移行完了時に自動停止
- GO後のNEXT送りと `←` `→` キーは**セッション内でループ**します(末尾の次は先頭)
- 「◉ 今の音をシーンに保存」でいま鳴っている音量を新規シーンとして保存。**セッション / Scene ID / Scene Name / 遷移モードを1つのフォームで入力**します。「上書き」は再生中シーンに対して同じフォームで実行
  - 保存値は `max(シーン値, 割り込み値)` の**焼き込み**です。保存すると割り込みフェーダーは0%に戻りますが、**聞こえる音は保存前後で変わりません**
- **MUTE ALL** は鳴っている音を即ミュート(シーンの保存値は変わりません)。もう一度押すと元の音に戻ります。**ALL STOP** は全停止でCURRENT/NEXTの選択も解除します
- シーンリスト各行の **🎚️** から、そのシーンの音量設定・音源の差し替え・削除ができます

### セクション「フェーダー(割り込み)」

- **上段: SEパッド** — 正方形グリッド。クリックまたは数字キー `1`〜`9` でカットイン。**再生中にもう一度押すと停止**します(再生中のパッドは点灯)。SEが9件を超えるとバンク(A/B/C…)が出て、数字キーは現在バンクの1〜9に対応します
- **下段: 割り込みBGMフェーダー** — フェーダーNoを割り当てたBGMだけがスロット番号順に並びます。**シーンの保存値は一切書き換えません**。シーン遷移後も割り込み値は維持され、0%に戻せば通常のシーン値に戻ります
- 各フェーダーの下の **■ 停止** で強制的に0%＆再生停止。停止後はボタンが **▶ 途中から / ⏮ 最初から** の2択になり、再開位置を選べます

### シーンの遷移モード(5種)

OUT(今の音源)× IN(次の音源)の組み合わせで指定します。フェード秒数は OUT / IN それぞれに適用されます。

| # | モード | 動き |
| --- | --- | --- |
| 1 | クロスフェード | OUTフェードとINフェードを同時に行う |
| 2 | フェードアウト → フェードイン | OUT完了後にIN開始(所要時間はフェード秒×2) |
| 3 | フェードアウト → カットイン | OUTをフェードし、完了と同時にINをカットイン |
| 4 | カットアウト → カットイン | 一瞬で切り替え |
| 5 | カットアウト → フェードイン | OUTを即0にして、INをフェードイン |

**詳細編集 → シーン編集** では、最上部の**ワイン色の枠が入力用カード**です。Scene ID / 名前 / 遷移モード / フェード秒 / 各BGMの%を入れて「＋ 追加登録」すると、そのまま下の一覧に並びます。登録済みカードは同じ見た目で、その場で編集・削除できます。

はじめて触る場合は **設定 → デモ一式を生成** でデモ音源とシーンが自動生成されます(5つの遷移モードを1つずつ使ったシーンができます)。動作確認用に **ダミー音源を200件生成**(開発用)もあります。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Enter` | GO(シーン切替) |
| `←` / `→` | NEXTシーン選択(セッション内でループ) |
| `Space` | 全停止 |
| `1`〜`9` | SEパッド再生 / 再押下で停止(現在バンク) |

## データ保存

- 既定は**ローカルモード**: 音源Blobとメタデータを IndexedDB に永続保存(完全オフライン動作)
- **エクスポート / インポート**: 全データを1ファイル(`.ssopack.json`)に書き出し、別端末へ移行可能
- データ形式は **version 2**。旧データは起動時に自動移行されます
  - v1 → 既存シーンは「セッション 1」に所属し、Scene ID が 1, 2, 3… と付与されます
  - 遷移モードを持たない旧データ → `フェード` は「1. クロスフェード」、`カット` は「4. カットアウト → カットイン」に移行されます
  - v1 / v2 の `.ssopack.json` もそのままインポートできます

## Google Drive 同期(任意)

自分のGoogleアカウントのDriveに `SessionSoundOperator` フォルダを作り、`state.json` と音源ファイルを同期します。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成し、**OAuthクライアントID(ウェブアプリケーション)** を発行
   - スコープは `drive.file` のみ(このアプリが作成したファイルにしかアクセスしません)
   - 承認済みJavaScript生成元に配信URLのオリジンを登録
2. アプリの **設定 → Google Drive 同期** にクライアントIDを入力して「接続して同期」

> **注意**: OAuthの仕様上、**httpsで配信されたURLで開いている必要があります**。ローカルファイル直開き(`file://`)ではDrive同期は使えません。GitHub Pages(Settings → Pages → main ブランチ)で公開するのが手軽です。
>
> GitHub Pagesで公開した場合のURLは `https://onoayami.github.io/session_sound_operator/sound.html` です(`index.html` ではないので末尾のファイル名まで含めて開いてください)。

## OBS連携

- ブラウザのタブ音声をOBSの「アプリケーション音声キャプチャ」等で取り込む
- またはOBSの**ブラウザソース**として配信URLを読み込む(操作は別ウィンドウ推奨)

## 技術メモ

- 再生エンジン: Web Audio API(マスター / シーン / SE のゲインバス構成)
- 内部の音量値は 0〜1000 で保持し、表示・入力時に % へ変換しています
- 外部依存はGoogle Identity Services(Drive同期利用時のみ動的読み込み)だけ
- ビルド不要。`sound.html` を配るだけで動きます
